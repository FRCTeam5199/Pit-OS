5199's PitOS Setup Page

PitOS runs in a web browser which is fullscreened.
You can use F11 to turn off fullscreen so you can connect to the internet.
Just simply hold "fn" and press "F11" to disable fullscreen.
When you're done connecting to the internet, move the window to the monitor you want pitOS on, and hold "fn" and press "F11" to re-enable fullscreen.
